# Cryptographic Encryption Vault

## Description
This project encrypts and decrypts all files in a folder using Python and the Fernet encryption algorithm.

## Features
- Encrypts all files in a folder
- Decrypts encrypted files
- Generates a secure encryption key
- Uses the cryptography library

## Requirements
- Python 3.x
- cryptography library

## How to Run

1. Install the required library:
   pip install cryptography

2. Run the program:
   python vault.py

## Output
The program encrypts all files in the `test_folder` and then decrypts them successfully.
